# 06 — Package the MCP server as a Kiro Power (separate repo: boston-311-power)

A Power installed from a GitHub URL needs POWER.md at the repository root.

"Create a Kiro Power in this repo: POWER.md (frontmatter with name, displayName, description, and activation keywords such as 'Boston 311', 'zombie', 'service requests'; overview; tool documentation with examples; do/don't best practices), mcp.json pointing to the Undead 311 MCP server, and steering/ with 311-data.md and zombie-definition.md. Then install it locally via the Powers panel (Add power from Local Path) and verify by asking 'What Boston 311 tools are available?'"
