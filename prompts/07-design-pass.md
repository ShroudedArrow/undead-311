# 07 — Human design and copy pass (after the one-shot build; repeat once before the freeze)

1. **Generic check.** Ask Kiro: "Describe what a generic AI-generated version of this page would look like (palette, type, layout, motion, copy). Then list every place our current page matches that description." Fix each match.
2. **Swap test.** Remove the name and logo from a screenshot. If it could be any civic dashboard or SaaS product, the design isn't done.
3. **Remove one accessory.** On each screen, delete one decorative element that carries no information.
4. **Copy pass.** You (not Kiro) replace every TODO-COPY marker, reading each line aloud. Run `make copy-lint`.
5. **Outside eyes.** Show three people outside the team the screenshots for 10 seconds each. Ask: "What is this, and what do you remember?" If the answer is "a dashboard", push the signature elements harder.
6. **Real assets in.** Swap every placeholder image/marker for the team's spray-paint circles and street photos.
