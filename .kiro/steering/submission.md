# Kiroween 2026 submission checklist (use with #submission)

- Category: Frankenstein. Bonuses: Best Student Project (Frankenstein), Best Kiro Crew App, Blog, Social Blitz, Ghost of Kiroween Past (if eligible).
- Public GitHub repo; OSI license visible in the About section; `/.kiro` at root and not gitignored; all source, assets, instructions.
- Working URL with judge mode, no login; must stay up and free until Jan 29, 2027.
- Demo video < 3 min, public on YouTube, shows the app working; no copyrighted music or third-party trademarks.
- Kiro write-up: IDE/CLI/Web/Crew, custom agents, hooks, specs, steering, MCP, property-based testing, powers, workflows; what Kiro got wrong.
- Student details for all members (LinkedIn, student email, year/degree, school).
- Crew App: separate public repo + description (same GitHub account).
- Blog (mentions Kiroween 2026, third-party platform, published during the submission period). Social post starts with #KiroweenHackathon26.
- Disclose pre-existing code (frameworks/libraries only) and data licenses in README.
- Deadline: Dec 4, 2026, 2:00 PM PT. Internal freeze Dec 2.
