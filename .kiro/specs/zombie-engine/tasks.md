# Tasks: zombie-engine

Tasks are tagged with their build layer. The build workflow implements every `[demo-critical]` task in all specs first, then `[credibility]`, then `[delight]`. Each task ends with `make test` passing, `ruff check` clean, tests that cite requirement IDs, and one line in docs/KIRO_LOG.md (testing.md definition of done). Property tests are separate sub-tasks so they are never skipped.
